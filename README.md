# aboud
متجر شحن العاب وتطبيقات

## إعداد الاتصال بقاعدة البيانات (PDO)

تم إضافة ملف اتصال جاهز داخل `src/db.php` مع **Singleton** وقراءة الإعدادات من متغيرات البيئة (مع دعم ملف `.env` محلياً).

### الخطوات السريعة

- انسخ ملف المثال:
  - انسخ `.env.example` إلى `.env`
- عدّل القيم داخل `.env` حسب بيانات قاعدة بياناتك
- **مهم**: ملف `.env` يتم تجاهله تلقائياً داخل git (لا يتم رفعه)

### الاستخدام

مثال بسيط:

```php
<?php
require __DIR__ . '/src/db.php';

$pdo = getDBConnection();
$stmt = $pdo->query('SELECT NOW() AS now');
var_dump($stmt->fetch());
```
